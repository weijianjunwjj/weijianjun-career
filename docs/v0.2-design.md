## Visual system

- 深黑蓝 #080c12、分层冷灰 #101722，暖白 #f0f3f8，冷青 #83e8da；仅少量电蓝作为技术线条。
- Editorial 非对称布局，细分隔线与编号；避免等宽卡片墙和标签墙。
- Hero：BUILD / BEYOND / FRONTEND. 超大排版，中文身份和真实职业摘要形成第二层。
- NovaWing：全宽证据画面 + 问题陈述 + 可审查流程。
- Evolution：以真实工作年限为依据的跨越式排版，不给没有日期的个人项目添加年份。
- 桌面正文 18px，次级 15px，标签 14px，Hero 64–96px，H2 36–52px。
- 手机正文 16px，次级 14px，标签 13px，Hero 42–58px，H2 30–40px。
- 只允许装饰性编号 / eyebrow 小于上述字号；信息文字行高 1.55–1.75。
